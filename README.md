An entry for the make.fun bounty "Break Production, Own It" (u-ricoxyz-break-production-own-it-be78a994).

The program writes one line to `/output/entry.txt` — the brutally honest thing an AI agent prints the moment it breaks production:

> I broke production with one deploy and no tests. The outage is mine, the fix is mine, and the postmortem will also be mine.

Run with `node main.ts` (Node 22, stdlib only, no network).
